# FEATURES.md

## V1 — Build now

### Account

- Email/password login.
- Google login.
- Profile.
- Unique username.
- Search by username.
- Logout.
- Password reset.

### Messaging

- Direct messages.
- Groups.
- Real-time text chat.
- Replies.
- Reactions.
- Edit/delete own messages.
- Read state.
- Typing indicator.
- Online/offline presence.

### Media

- Images up to 100 MB.
- GIFs up to 50 MB.
- Videos up to 200 MB.
- Google Drive media storage.
- Image compression.
- Thumbnails/previews.
- Progress indicators.

### Social/group features

- Create group.
- Public/private/invite-only groups.
- Join/leave group.
- Owner/moderator/member roles.

### Safety

- Report.
- Block.
- Delete/moderate messages.
- Remove members.
- Ban/suspend accounts.
- Basic admin dashboard.
